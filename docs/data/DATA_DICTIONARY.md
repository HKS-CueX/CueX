# CueX Data Dictionary (`@cuex/protocol` v2 & SQLite Storage Entities)

> Authoritative Contract: `packages/protocol/src/` (`API_VERSION = '2026-11'`, `PACK_SCHEMA_VERSION = 2`, `EVIDENCE_SCHEMA_VERSION = 2`, `MEMORY_SCHEMA_VERSION = 2`)  
> Storage Backing Target: `apps/server/src/storage/` (`SqliteStorageRepository` via `node:sqlite`, `migrations.ts`, `ADR-001`)  
> Conventions: Wall-clock fields use `UtcIso8601`; durations/offsets use numeric `*Ms` / `*Sec`; monetary amounts use `MoneyAmount { amountFen: integer, currency: 'CNY' }`.

---

## 1. Universal Primitives & Value Objects

| Symbol | Fields / Values | Invariants & Purpose |
| --- | --- | --- |
| **`UtcIso8601`** | `string` (`YYYY-MM-DDTHH:mm:ss.sssZ`) | Mandatory wall-clock timestamp format (`createdAt`, `updatedAt`, `occurredAt`, `startedAt`, `endedAt`, `expiresAt`, `timestamp`). |
| **`MoneyAmount`** | `{ amountFen: integer; currency: 'CNY' }` | Integer minor units (`Number.isSafeInteger(amountFen)` & `>= 0`). Unified `PlanCatalog.ts` uses `Free 0` (`2` sessions, `20m` cloud ASR), `Event 2900` (`¥29.00` / 14d, `120m`), `Pro 5900/mo` / `49900/yr` (`¥59/mo · ¥499/yr`, `240m`), `Team 19900/seat/mo` (`planned`, `1000m`), matching `docs/business/PRICING_AND_PACKAGING.md` (all marked `isCommercialHypothesis: true`). |
| **`InterventionLevel`** | `'L0' \| 'L1' \| 'L2' \| 'L3'` | Progressive intervention rank (`0..3`): Silence (`L0`), Edge Glow (`L1`), 2–6 char Keyword (`L2`), Short Scaffold (`L3`). |
| **`TelemetryUsageSource`** (`TelemetryMeasurementSource`) | `'provider_reported' \| 'local_rule_zero' \| 'estimated'` | Strictly separates API-reported token counts, exact `0`-token local deterministic rules, and explicit estimations. |
| **`TelemetryUsage`** | `{ sessionId, updatedAt, usageSource, inputTokens, outputTokens, cachedInputTokens, totalTokens, modelCalls, retries, localRuleEvaluations, latencyMs, latencyStats: { avgMs, p95Ms, maxMs }, degraded, usingLocalFallback, asrProvider, asrDurationMs, costFen, cost, estimation, byTier? }` | Auditable multi-tier telemetry; local rule evaluations record `0` tokens & `costFen: 0`; `cachedInputTokens` never fabricated. |
| **`ApiErrorResponse`** | `{ ok: false, error: { code: ApiErrorCode, message, httpStatus, retryable, correlationId?, requestId?, timestamp, details? } }` | Unified REST & WS error envelope across all 14 `API_ERROR_CODES` (`VALIDATION_ERROR`, `UNAUTHORIZED`, `FORBIDDEN`, `NOT_FOUND`, `RATE_LIMITED`, `PROVIDER_TIMEOUT`, `PROVIDER_UNAVAILABLE`, `QUOTA_EXCEEDED`, `SCHEMA_VERSION_UNSUPPORTED`, `SESSION_EXPIRED`, `ASR_UNAVAILABLE`, `INSUFFICIENT_EVIDENCE`, `PAYMENT_NOT_CONFIGURED`, `INTERNAL_ERROR`). |
