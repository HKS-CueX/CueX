# CueX End-to-End Data Pipeline (Ingestion -> Analytics)

> Scope: Complete 9-stage data flow from pre-stage document ingestion through live cognitive intervention to durable SQLite storage, usage metering, privacy export/wipe, and operational telemetry.  
> Implementation Mapping: `apps/server/src/{gateway,runtime,scenarios/presentation,storage,commercial,security,observability,pipeline}/`

```text
[1. Ingestion & Bounds] ─► [2. Extraction] ─► [3. Compilation & Grounding]
         │
         ▼ (Session Start: Auth + Entitlement Check)
[4. Speech Intake & ASR] ─► [5. System 1 Fast Decision] ─► [6. Retrieval & System 2]
                                                                    │
[9. Reflection & Telemetry] ◄─ [8. SQLite & UsageLedger] ◄─ [7. InterventionController]
```

---

## The 9 Data Pipeline Stages

| Stage | Subsystem & Boundary | Inputs | Processing & Invariants | Outputs / Sinks | Privacy & Failure Handling |
| --- | --- | --- | --- | --- | --- |
| **1. Document Ingestion & Security Validation** | `GatewayServer` + `DocumentExtractor` | `.pptx`, `.pdf`, `.md`, `.txt` upload (`base64` / text) | Enforce `CUEX_MAX_UPLOAD_MB` (`15 MB` default), validate bearer token (`auth_tokens`), verify magic bytes & MIME hints, enforce ZIP entry-count (`<= 512`), bounded decompression output length, and compression-ratio bounds (`ADR-001`). | Validated buffer (`in-memory only`) or `status: 'rejected'` (`VALIDATION_ERROR`) | Rejects ZIP bombs & path traversal cleanly; raw unparsed binaries are discarded after extraction. |
| **2. Structured Extraction** | `DocumentExtractor.ts` | `.pptx` ZIP XML, `.pdf` streams, `.md`/`.txt` UTF-8 | Extract `slide*.xml` + speaker notes (`DrawingML <a:p>/<a:t>`), best-effort PDF `Tj`/`TJ` operators, Markdown headings; compute `SHA-256` `contentHash` (`Evidence` provenance). | `PresentationExtractResult` (`status: 'parsed' \| 'unreadable' \| 'rejected'`, `sections[]`, `warnings[]`) | Scanned/encrypted PDFs yield `unreadable: true` with paste-text guidance; never fabricates text. |
| **3. Compilation & Evidence Binding** | `PresentationCompiler` + `PresentationPackStore` / `SqliteStorageRepository` | `PresentationCompileInput`, user edits/locks (`PATCH /api/presentation/packs/:packId`) | Compile `CueSheet`, `facts[]`, `evidence[]` (`EVIDENCE_SCHEMA_VERSION = 2`), predicted `qaCards[]` (`isPrediction: true`), and `progressNodes[]`; preserve `locked: true` items from overwrite; persist under owning `userId` (`tenantId`). | `PresentationContextPack` (`PACK_SCHEMA_VERSION = 2`) in SQLite `presentation_packs` | Records compile usage (`document_extract` / `context_compile`) in `usage_ledger`; built-in sample pack isolated read-only unless forked per user. |
| **4. Live Speech Intake & Normalization** | `AudioCapture` (Web) + `voice/` + `GatewayServer` (`/ws`) | 16 kHz PCM16/Opus `audio.chunk` or WS `speech.delta` (`browser_webspeech` / `text_simulation` / `external_asr`) | Stream speech across implemented modes (`local_sherpa`, `remote_sherpa`, `browser_webspeech`, `text_simulation`); apply demo hotword corrections when active (`SAMPLE_ASR_CORRECTIONS`); deduplicate client WS frames via `idempotencyKey`. | `TranscriptSegment` (`segmentId`, `speaker`, `startMs`, `endMs`, `chapterId`, `source`) | Raw audio chunks process transiently in stream buffers and are not persisted as recordings (`PRIVACY_DATA_MAP.md`). |
| **5. Fast Cognitive Assessment (System 1)** | `FastDecisionAdapter` (`Heuristic` / `LlamaSystemOne` / `FallbackFastDecisionProvider`) | `TranscriptSegment`, chapter context, silence ticks | Run deterministic local rules (`local_rule_zero`, 0 LLM tokens) or optional `llama.cpp` `/completion`; classify `cognitiveState` without triggering System 2 during pure rhetorical pauses. | `FastDecisionVerdict` + `Observation[]` + `CognitiveEvent` (`EventEnvelope`) | `FallbackFastDecisionProvider` falls back to local deterministic rules cleanly on upstream timeout/error (`PROVIDER_TIMEOUT` / `PROVIDER_UNAVAILABLE`). |
| **6. Grounded Retrieval & Slow Synthesis (System 2)** | `LexicalBm25RetrievalProvider` + `SlowReasoningAdapter` | Detected omission / drift / live Q&A + verified `active` `Evidence[]` | Search confirmed `Evidence[]` via BM25; synthesize grounded `Candidate` via `LocalSlowReasoningProvider` or `PiSlowReasoningProvider` (with `redact()` secret masking & `AbortController` preemption on new final speech). | `SlowReasoningCandidateResult` (`grounded`, `evidenceIds[]`, or `missingEvidenceNotice`) | Refuses fabricated metrics/evidence; zero cross-scenario shared KV cache claimed. |
| **7. Policy Arbitration & Envelope Dispatch** | `InterventionController` + `SharedCognitiveState` + `EventPipeline` + `GatewayServer` | `Candidate[]`, `TaskContext`, active `Intervention`, user controls (`paused`, `silent`, `ceiling`, `dismiss`) | Enforce 11 ordered gates + 7 `WithdrawalReason` transitions; wrap outbound `ServerMessage` with `EventEnvelopeMeta` (`privacyClass`) and monotonic `serverSeq`; support `/ws?token=...&sessionId=...&lastSeenSeq=...` reconnect replay while skipping inactive cues. | `ControllerDecision`, `intervention.shown`, `intervention.withdrawn` | `silentMode` (`L0`) and `pause_only_without_gap` suppress non-essential nudges; active cues auto-withdraw once speaker recovers. |
| **8. Transactional Operational Storage & Metering** | `SqliteStorageRepository` (`node:sqlite` WAL) + `CommercialService` | Session lifecycle events, `TelemetryUsage`, billing webhooks | Atomically persist `users`, `auth_tokens`, `presentation_packs`, `sessions`, `session_events`, `session_reflections`, `memories` (`userConfirmed === true`), `entitlements`, idempotent `usage_ledger`, `telemetry_records`, and `billing_audit_log`. | Durable `.cuex-runtime/cuex.db` rows surviving restarts; `AccountUsageSummary` | Atomic quota reservation on `session.start` (`402 QUOTA_EXCEEDED`); user/tenant ownership checks across every protected route. |
| **9. Reflection, Single-Point Rehearsal & Telemetry** | `PresentationReflection` + `MetricsRegistry` + `GET /api/observability/summary` | Completed `Session`, interventions, H/I feedback, `TelemetryUsage` | Compute $V = H - \lambda I$ (`λ = 2`), chapter overtime, missed key points, `weakSegments[]` for targeted `rehearsal.start`, and pending opt-in `MemoryProposal[]`; emit operational counters via `MetricsRegistry` & `EventPipeline` **without raw transcript text**. | `PresentationReflection`, rehearsal seed, `/api/observability/summary`, `UserDataExportBundle`, `DataDeletionReceipt` | Unconfirmed `MemoryProposal`s never enter SQLite `memories`; `session.wipe` / `DELETE /api/account/data` remove runtime records synchronously. |
