> - 全部定价、转化漏斗、留存与获客数字均属于 **`[商业假设]`**；核心评估性能数据（平均 `0.88 ms` / P50 `0.66 ms` / P95 `1.66 ms`、`6/6` 通过率）为 **`[本地实测 Eval]`**；Phase 3 实机端到端验证数据（Colab GPU `SenseVoiceSmall` 均耗时 `52.57 ms` / `0.00327 RTF`、CPA `gemini-4-hydrogen` S1 `6/6` 与 `14/14` Section 5.2 全场景 E2E）为 **`[Phase 3 实机遥测]`**；云端成本与支付通道费率基于 **`[云端公开费率]`**（`2026-11-16` 核验）与 **`[模型估算]`**。
> - Phase 2 服务端仅完成 `UsageLedger / Entitlement / PaymentProviderAdapter` 沙盒契约，**尚未开通真实商户收单，当前无真实商业营收**。

## 1. 品牌定位与商业楔子（Wedge）

- **母品牌定位**：**CueX —— 你的快思考外挂，在深度思考之外，接住当下。**
  - 长期目标是在多类高信息密度即时表达场景中充当最小必要干预的实时认知协作者。
- **首个可商业化楔子**：**`CueX Presentation`（演讲与答辩临场引导师）**
  - 解决传统静态提词器（只读逐字稿、不支持实时脱稿偏航纠偏）与通用会后纪要工具（只做录音转写总结、不管台上 3 秒内接话）之间的结构性空白。
  - 交付核心并非“替你背诵全文”，而是“**默认 L0 静默不打扰；仅在忘词卡壳、偏离大纲或遇到现场 Q&A 追问时，依据经过人工审批的材料白名单 (`Evidence[]`) 毫秒级浮出 ≤8 字要点或证据锚点，并在演讲者回到正轨或切章后自动撤回**”。

## 2. 优先级分层客户群（P1 → P2 → P3）

遵循 [客户验证方案](CUSTOMER_VALIDATION.md) 与 [路线图](ROADMAP.md)，商业推广按痛点强度、支付意愿与可触达性严格排序：

1. **P1 首发核心（OPC 一人公司创始人 / 早期路演负责人）** `[商业假设]`
   - **典型场景**：投资人路演、大客户方案汇报、竞赛答辩（10–25 分钟高频短打）。
   - **核心需求**：高密数字、竞品口径与财务边界绝不能在台上说错或编造；需要基于自家真实 BP/产品资料库的“可撤回轻量拐杖”，且高频演练值得为时间效率与零失误付费。
2. **P2 刚需扩圈（高校硕博研究生 / 学术报告与毕业答辩人群）** `[商业假设]`
   - **典型场景**：开题、中期、预答辩、毕业答辩及学术会议 Oral Presentation。
   - **核心需求**：面对评审专家临时跨页追问实验细节时保持沉着、不编造论文中没有的指标；付费冲动集中在答辩前 1–2 周内，完美匹配 `CueX Event` 单场包。
3. **P3 纵深拓展（专业讲师 / 解决方案架构师 / 独立培训师）** `[商业假设]`
   - **典型场景**：标准化课程反复授课、跨客户技术布道与季度复盘。
   - **核心需求**：沉淀长期可复用的口径白名单（`CueSheet` + `approval memory`），对低打扰率、可审计性与稳定订阅高度敏感，构成中期 `CueX Pro` 与 `CueX Team` 升级基石。

- **统一验证队列（Seed Cohort）**：**`第 1 轮 20–30 名真实目标用户 → 第 2 轮扩展至 30–50 人`**（先行深度闭环 OPC 创始人与毕业答辩高频样本，完成 ≥3 轮“彩排-上台-复盘”后再向扩展队列放量）。

## 3. 关联型 8 要素商业模式画布（Connected BMC）

| 画布要素 | CueX 核心商业设计 | 要素间因果咬合逻辑 |
| --- | --- | --- |
| **1. 价值主张** | **L0 零打扰默认静默 + 关键时刻可控微提示 + 100% 证据绑定防幻觉 + 瞬时自动撤回** | 不让“提词器弹窗本身”制造新的认知负担；建立用户敢在关键场合开启产品的信任基础 |
| **2. 客户细分** | `P1` OPC 创业者与路演负责人 → `P2` 硕博答辩生 → `P3` 职业讲师/架构师 | P1 贡献初期高频率 Pro 验证；P2 提供密集 Event 节点现金流；P3 沉淀团队化口径库 |
| **3. 渠道通路** | 内容 Demo 裂变（偏航撤回+资料外诚实拒答实录）→ OPC/孵化器训练营 → 毕业季社群与模板包 | 完整路线见 [市场进入方案](GTM_PLAN.md) 12 步商业漏斗 |
| **4. 客户关系** | 个人审批记忆（只记“被批准的提示偏好”与高频卡点）+ 自助可视化 `Inspector` | 用越久越懂你的卡顿边界而非越聊越啰嗦；减少重人工客服介入 |
| **5. 定价与收入流** `[商业假设]` | `Free ¥0`（引流体验）→ `Event ¥19–39`（锚点 `¥29`，14 天单场包）→ `Pro ¥59/月 或 ¥499/年`（主力）→ `Team ¥199/席/月 [Planned]` | Event 消除非高频用户的订阅抵触；Pro 承接高频演练；详见 [定价与包装](PRICING_AND_PACKAGING.md) |
| **6. 关键活动** | 离线+云端混合规则编排、材料白名单编译、单会话同前缀提示优化、基于沙盒账本的阈值微调 | 直接压低云端 LLM 与盲目唤醒成本，同时防止超限算力滥用 |
| **7. 核心资源** | 通用 `CueX Runtime` 状态机（Intervention Controller）、`Presentation` 协议栈、多端采集适配层 | 从 Presentation 平滑向后续新场景复制内核，而不重写控制大脑 |
| **8. 核心伙伴与成本结构** | 上游云端流式 ASR（第一成本 `54.4%`）与推理模型供应商；微信支付（`0.6%`）/支付宝（`0.6%`） | 成本明细见 [单位经济模型](UNIT_ECONOMICS.md)：Base 单场全成本 `¥0.612`，Pro 直接贡献率 `83.8%` |

## 4. 商业闭环核心数字与财务边界（单一事实源对齐）

> 全部计算结果锁定于 [`cuex-final-metrics.json`](../../ppt/scripts/cuex-final-metrics.json)（`EVAL_LOCKED`，基准情景下以 `¥59/月` Pro 及 `¥29` Event 锚定，`2026-11-16` 核验支付与 ASR 公开费率）：

- **定价梯度** `[商业假设]`：
  - `CueX Free (¥0)`：每月限 `2 场 × 10 分钟` 云端 ASR + 完整 `Inspector` + 本地/浏览器降级。
  - `CueX Event (¥19–39 / 场，锚点 ¥29)`：`14 天`有效，含 `120 分钟` 云端 ASR 演练、正式临场与赛后复盘。
  - `CueX Pro (¥59 / 月，¥499 / 年)`：每月含 `240 分钟` 云端 ASR、长期审批记忆、无限材料包编译。
  - `CueX Team (¥199 / 席位 / 月 [Planned])`：共享证据白名单与团队审计（Phase 2 尚未开发完成）。
- **收益与成本质量（Base 基准情景）** `[云端公开费率 + 模型估算]`：
  - 单场 25 分钟全可变成本 **`¥0.612`**（其中纯 LLM **`¥0.098`**，云端 ASR `¥0.333` 占比 `54.4%`，基础设施 `¥0.180`；仅计量单会话内同前缀缓存节省 `-¥0.020`，无跨体共享）。
  - 支付通道拆分微信支付 `0.6%` 与支付宝 `0.6%`（`2026-11-16` 官网核验退款等比退回通道费；保守情景下另行测试微信虚拟类目 `1.0%` 风险与 `5%` 退款率）。
  - Pro 月净营收（扣 `2%` 退款假设）**`¥57.82`**，扣减含 `12:1` 算力活跃免费补贴后的直接贡献 **`¥48.45 / 月`**（**直接贡献率 `83.8%`**；纯 SaaS 交付毛利率 **`92.2%`**）。Event 单包贡献率 **`87.3%`**（保守 `62.0%`，乐观 `95.6%`）。
- **单户安全边际与公司盈亏边界**：
  - 单 Pro 用户月可承受场次上限 `maxAffordableSessionsPerProMonth`：**`85 场/月`**（保守 **`29 场`**，乐观 **`211 场`**）。
  - **公司总盈亏平衡点尚未测算**（未纳入固定研发人力、市场费用与基础底座开销，参见 [单位经济模型 §5.3](UNIT_ECONOMICS.md)）。
- **当前工程真实边界**：
  - `V = H − λI`（`λ = 2`，本地实测 `+3`）属于探索性效用度量，将与 [客户验证方案](CUSTOMER_VALIDATION.md) 的 `第 1 轮 20–30 名 → 第 2 轮扩展至 30–50 人` 种子队列主客观数据合并校验后再固化工序。
