## 1. 七大竞品与替代生态全景

围绕「**高认知负荷实时沟通与演讲答辩辅助**」，真实竞争格局并非只有“同类 Copilot”，而是由 **七类供给共同构成**：

1. **传统声控提词器（Traditional Voice-Tracking Teleprompters）**：代表 **PromptSmart**
2. **实时语音教练与演讲分析（Live Speech Analytics Coaches）**：代表 **Poised AI**（已正式停服）、**Yoodli AI**
3. **AI 角色扮演与彩排训练（AI Rehearsal / Roleplay Platforms）**：代表 **Yoodli Roleplay** 等
4. **重型实时答案外挂/作弊器（Live Answer Copilots）**：代表 **Final Round AI**、**Cluely**
5. **会议转录与会后纪要机器人（Meeting Transcription / Notetakers）**：代表 **Otter.ai**、**Read.ai**
6. **演示文稿与自带演讲教练（Presentation Software & Built-in Coaches）**：代表 **Microsoft PowerPoint Speaker Coach**、**Gamma.app**、**Pitch.com**
7. **国内语音纪要与办公套件（Domestic Meeting & Note Suites）**：代表 **通义听悟（阿里云）**、**飞书妙记（字节跳动）**

## 5. CueX 真实差异化与“伪护城河”否定清单

### 5.1 我们明确放弃的伪命题（Never Claimed as Moats）
- ❌ **不宣称“让大模型输出短词”是壁垒**：任何团队改两行 Prompt 就能让模型吐出 5 个字，毫无可防卫性。
- ❌ **不宣称“接入了某家大模型或流式 ASR”是壁垒**：底层模型与 ASR 正在快速商品化降价，调用 API 本身不是壁垒。
- ❌ **不宣称“跨场景/跨槽位共享物理 KV Cache”是壁垒**：`llama.cpp` 通用槽位并不天然跨槽共享 KV，仅单会话前缀命中属于所有客户均可享受的公开接口能力。

### 5.2 CueX 已落实代码的工程化真差异化
1. **`L0` 默认静默 + 独立 `InterventionController` 五重门控**：生成 ≠ 弹出。候选必须依次通过静音/暂停检查、版本号 `contextVersion` 一致性、`TTL` 过期、证据绑定（`grounded`）与冷却上限，并在不适合干预的纯停顿窗口实现 `0` 弹出。
2. **7 类 `WithdrawalReason` 自动撤回状态机**：演讲者开口自行拉回正轨（`user_recovered`）、切换章节（`chapter_changed`）或语境变更瞬间自动撤回提示卡片，把舞台视觉焦点还给人脑。
3. **场前本人锁定 `Evidence[]` + 诚实 `unpreparedGaps` 防幻觉边界**：绝不在高风险路演/答辩中由 AI 现场捏造核心数字；缺依据时直接提示未准备（`missingEvidenceNotice`）。
4. **探索性 `V = H − λI` 量化复盘 + 人工审批 `MemoryStore`**：把“多嘴打扰”设为 `2×` 惩罚纳入反馈闭环，并通过显式勾选（`userConfirmed === true`）与一键全擦除构建信任复利。
5. **Universal Runtime + `ScenarioAdapter` 解耦架构**：同一个核心状态机与仲裁门控从已落地的 `CueX Presentation` 向未上线的 `Sales / Teaching / Social / Custom` 平滑迁移，摊薄长期研发成本。
