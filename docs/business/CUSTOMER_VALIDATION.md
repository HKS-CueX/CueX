# CueX 客户验证方案与需求访谈手册（Customer Validation）

> **口径统一说明**：与 `BUSINESS_MODEL.md` 及 `ROADMAP.md` 完全一致——种子期市场验证采用两轮递进队列：**第 1 轮 `20–30` 名真实高频目标用户深度陪跑 → 第 2 轮扩展至 `30–50` 人规模化转化检验**。所有预期通过标准均属 **`[验证假设 / 实验门控]`**，尚未执行大规模真机投放。

## 2. 六大核心待办任务（6 Core Jobs-to-be-Done）

1. **JTBD-1（快速降维编译讲稿）**：*“明天就要路演/预答辩，手头只有一版 30 页杂乱 PPT 和零散备忘，我需要 3 分钟内自动理出‘每章必讲死命令、关键数字防误线和评委最可能追问清单’，而不是花半天手写逐字稿。”*
2. **JTBD-2（脱稿自然表达不翻车）**：*“上台时我希望靠理解自然流利脱稿讲，不需要盯着大屏幕念词；但大脑突然空白卡壳的 2 秒内，只要余光瞥见 2–6 个关键词就能自己顺下去。”*
3. **JTBD-3（高压跳页与即兴追问兜底）**：*“如果评委或投资人中途打断让我直接跳到商业成本或技术难点，我需要系统立刻同步新话题，调出我本人在讲稿里确认过的依据数字，而不是傻傻停在旧页或胡编数据。”*
4. **JTBD-4（说完立刻消失的隐形克制）**：*“只要我自己想起来或顺过那个坎了，我需要提示自己赶紧消失，绝不能一直在角落亮着刺眼文字打断我接下来的表达思路。”*
5. **JTBD-5（针对薄弱片段的精准重练）**：*“彩排完不要告诉我‘你的演讲整体 82 分加油’这种废话；告诉我具体哪一章漏了必讲指标、哪一分钟语速偏失控，点一下就直接重练那 90 秒。”*
6. **JTBD-6（可控且可擦除的个人偏好记忆）**：*“我希望系统记住我总爱漏讲毛利率口径或常被问到竞品，但涉及我个人商业数据或敏感项目底稿，必须让我自己点‘允许写入’才保留，答辩完能一键销毁痕迹。”*

## 3. 十道非引导式行为访谈问题（10 Behavioral Interview Questions）

> **访谈纪律（Mom Test 原则）**：严禁问“*如果 CueX 只提示 4 个字且能自动撤回，你愿意每月付 59 元吗？*”这类诱导性未来假设题；全部围绕**受访者过去 3 个月真实发生过的路演/答辩瞬间、失败经历与实际花钱动作**展开提问。

| 编号 | 核心探索方向 | 访谈原问题（围绕真实过去行为） | 观察关键信号 |
| :---: | :--- | :--- | :--- |
| **Q1** | 高压情景回溯 | “请带我回到你最近一次最紧张、容错率最低的路演、提案或论文答辩现场——上台前最后 24 小时你是怎么准备讲稿的？” | 真实材料形态（PPT/Markdown/大纲）、碎片耗时痛点 |
| **Q2** | 忘词与卡壳代价 | “那场或者最近半年类似演讲里，有没有某个核心数据、过渡句或问题在台上突然‘大脑一片空白’的瞬间？当时你怎么圆过去的，事后后果如何？” | 确认高痛点是否真实发生于核心数字/逻辑分叉点 |
| **Q3** | 现有工具失灵证据 | “过去上台或开重要视频会时，你尝试过提词器、分屏小抄、演讲笔记或者任何 AI 实时工具吗？具体在哪一步放弃或出糗了？” | 真实替代方案壁垒、视觉分心/跳页卡死实证 |
| **Q4** | AI 信息过载痛点 | “如果在你卡壳那一秒，旁边屏幕一下子弹出一段 100 字的完整 AI 建议话术，根据你真实阅读习惯，你第一反应是照着念，还是觉得反而乱了节奏？” | 检验“大段文本反噬工作记忆”假设的真实存在性 |
| **Q5** | 编造风险容忍度 | “你在公开场合或面对投资人/导师最怕说错哪类话？有没有出现过辅助工具给出的说法与你实际产品/实验数据冲突的情况？” | 检验 `Evidence[]` 锁定与 `missingEvidenceNotice` 刚需权重 |
| **Q6** | 彩排反馈习惯 | “你平时彩排一般练几遍？是谁帮你听（自己录音、朋友、还是 AI 工具），练完之后怎么决定接下来重点改哪一段？” | 验证赛后结构化诊断与“单点重练”是否契合实际练习习惯 |
| **Q7** | 付费历史基准 | “过去一年里，你为了保过某一场重要汇报、面试或答辩，真实自掏腰包买过什么软件、课程、提词器或辅导服务？具体付了多少钱、当时为什么愿意/不愿按月续费？” | 用真实历史支出锚定 `Event ¥19–39` vs `Pro ¥59` 心理价位 |
| **Q8** | 低频 vs 高频节奏 | “数一下过去 6 个月，让你‘前一天睡不好觉’需要严阵以待的重要演讲/答辩/大客户提案一共发生了几次？接下来 3 个月预计有几次？” | 校准 P1/P2 真实月频与 `Event -> Pro` 转换概率 |
| **Q9** | 隐私与遗忘底线 | “如果你的商业融资计划书或未发表学术数据要上传进一个辅助系统做实时识别，哪类信息会让你当场关掉页面不敢传？事后你希望这些录音和记忆怎样被处理？” | 验证本地识别权重、人类审批写入与一键全擦除诉求 |
| **Q10** | 真实推荐阻力 | “假设下周你团队伙伴/同门师弟妹要答辩，什么情况下你会主动把一个辅助工具发给他，而什么前提下即便效果不错你也觉得不好意思或不敢推荐？” | 识别合规、社交面子及场前准备摩擦门槛 |

## 4. 两轮种子实测验证门槛（Pass / Pivot / Kill Gates）

### 队列执行节奏
- **第 1 轮（`n = 20–30` 名）**：手把手带测，观察全流程操作摩擦（重点看 `CompilerView` 编译是否卡壳、舞台 `Focus` 视图视线漂移次数、自动撤回时机主观感受）。
- **第 2 轮（`n = 30–50` 名）**：去除人工陪跑、仅用自助引导文档 + 线上沙盒下单链路测真实留存与支付意愿转化。

### 明确定量/定性判定标准 `[验证假设门槛]`

| 验证维度 | 过线标准 (Pass — 推进扩量) | 修正标准 (Pivot — 调整产品/定价) | 终止/重构警报 (Kill) |
| :--- | :--- | :--- | :--- |
| **核心工作流闭环率** | ≥ **70%** 种子用户在首周内独立完成 ≥1 场真实材料编译 + `Stage` 演练 + `Reflection` 复盘 | 40%–69% 完成闭环，主因卡在某单步操作或导入格式 | < 40% 能独立走完（说明交互复杂度或编译准确度不可接受） |
| **低打扰与接回感知** | ≥ **75%** 参与 ≥3 轮实测的用户评价“对比传统滚动提词器或大段聊天窗口更少抢视线”，且感知到明显主动撤回价值 | 50%–74% 肯定，但抱怨触发太迟或撤回不灵敏（需重调 `Controller` 冷却与 `λ` 权重） | < 50% 感到有帮助，多数用户直接关闭所有实时提示回到背稿 |
| **自然复练率 (7日留存)** | 完成首场后 7 日内自发开启第 2 场单点重练/新讲稿的比例 ≥ **40%** | 20%–39% 自发复用 | < 20%（沦为“看一眼新奇就卸载”的玩具） |
| **真实付费意愿 (Van Westendorp / 预付卡测试)** | 当展示最终 `Event (¥19–39)` 与 `Pro (¥59/月)` 沙盒订单卡时，目标样本 ≥ **25%** 愿意在真实下场答辩/路演前完成付费解锁或留下真实预购意向 | 仅在 `¥9.9–19` 价位有意愿，明确拒绝 `¥59/月`（需重设单场包主导营收模型或削减高价云 ASR 成本） | < 10% 付费意愿且用户明确表示“只愿白嫖免费版/用会议软件免费字幕替代” |
| **真实防幻觉零致命事故** | 测试样本中 `0` 起系统在未核验情况下编造关键指标且未附 `missingEvidenceNotice` 的漏检汇报 | 偶发跨段落提取噪音（需优化 `DocumentExtractor` 切片与锁定提示） | 频发虚假数字突破 `numbersIn` 与 `Evidence[]` 护栏 |
