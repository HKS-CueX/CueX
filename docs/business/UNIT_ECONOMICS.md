> 1. 本文档严格区分三类数据标签：**`[本地实测 Eval]`**（源自 `pnpm --filter @cuex/server eval` 即 `eval-presentation.ts` 实机跑批输出 `.cuex-runtime/eval-latest.json`）、**`[云端公开费率]`**（源自 2026 年阿里云、火山引擎豆包及微信/支付宝官方公开费率）与 **`[商业假设 / 建模测算]`**（商业定价、月活频次与付费转化比例尚未经历大规模真实收费验证）。

### 核心成本真相拆解（基准情景）
- **单场纯大模型费用（LLM Cost / Session = ①+③+④+⑤+⑥+⑦）**：**`¥0.098 / 场`**
- **单场全变动成本（Full Variable Cost / Session = LLM Cost + ② ASR + ⑧ Infra）**：**`¥0.612 / 场`**
- **关键洞察**：纯 LLM 仅占单场全变动成本的 **`16.0%`**，而 **流式 ASR（¥0.333，占 54.4%）与基础设施/长连接（¥0.180，占 29.4%）占去超过 83% 的单场边际成本**。任何只拿着大模型 token 价格宣称“96% 毛利”的模型都严重失真。

## 6. 商业结论（给评委与工程迭代的三条硬约束）

1. **绝不承诺“无限免费云端实时识别”**：敏感性第 3、8 项证明，若放任免费用户消耗高价云端流式 ASR，25:1 的免费比率就能吃掉近 10 个百分点毛利；`CueX Free` 严格配额 **每月 2 场×10m** 与鼓励彩排使用本地/文本模式，是商业健康的前提。
2. **用 `Event（¥19–39/场）` + `Pro（¥59/月）` 共同锁死盈亏边界**：即使单次 Event 用户在 14 天内集中预演 2–3 次（合计 60–75 分钟），基准全成本仅 **`¥3.59`**，直接毛利仍高达 **`87.6%`**；`Pro` 设定 **240 分钟/月云 ASR** 封顶与超额无缝降级策略，使其实际消费远在 **87 场** 盈亏平衡线之下。
3. **当前边界重申**：上述单位经济中的所有价格与转化均为 **`[商业假设 / 建模测算]`**，需在种子用户实测后结合真实云厂商账单进一步核销。
