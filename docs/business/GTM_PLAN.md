## 1. 冷启动切入原则：先赢下“高 stakes 单点时刻”，再扩大复用频次

演讲与答辩属于典型“低频高危”决策触发场景：平时不急，一旦临近路演或答辩前 72 小时，用户对“脱稿不翻车、数字不出错、跨页追问能接住”的焦虑度极高。因此 GTM 不投泛娱乐或泛效率词，而是围绕**精准节点 + 可视化信任证明**构建四大获客渠道：

1. **渠道 A：OPC 创业者社群与路演训练营（P1 核心切口）** `[商业假设]`
   - 切入机制：与一人公司社群、AI 开源黑客松、早期孵化器合作，提供路演彩排工作坊与专属 `CueSheet` 结构化模板包（如“投资人 10 分钟快筛包”、“技术架构 Q&A 防御包”）。
   - 核心价值：直接验证高层频次与 `CueX Pro (¥59/月)` 复购动力，单客获取可借助群体推荐压缩边际 `CAC`。
2. **渠道 B：高校硕博答辩节点精准渗透（P2 高确定性增量）** `[商业假设]`
   - 切入机制：围绕 3–5 月毕业答辩季、9–11 月开题/中期考核节点，在学术播客/经验社区与校园大使群体投放“毕业答辩救场清单 + `CueX Event (¥19–39)` 14 天彩排通关包”。
   - 核心价值：周期明确、口碑极易同实验室横向扩散，是冷启动期验证首单付费转换率最高效的池子。
3. **渠道 C：“对比实录短片 + 现场拒答透明演示”（自然传播引擎）** `[商业假设]`
   - 展示方式：不发空洞的概念海报，只制作 45 秒分屏对比实录——左侧正常流畅讲演时右侧控制台全程保持 **`L0 静默`**；进入偏航或被专家追问资料外问题时，右侧 `0.76 ms` 规则判定 + 仅浮现 `≤8 字` 短提示或诚实提示 `grounded=false（资料未包含，切勿编造）`，回到正轨后自动撤回。
   - 核心价值：精准筛选认同“不瞎提示、不替人编词”的高质量种子用户，降低误预期带来的后续退款。
4. **渠道 D：结构化材料模板库与专业讲师口碑扩散（P3 中期纵深）** `[商业假设]`
   - 切入机制：让首批专业讲师与技术架构师导出脱敏版结构化框架模板（含章节大纲与常见异议锚点），形成自带产品水印与交互体验入口的裂变闭环。

## 2. 四层用户人群口径与 12 阶段完整商业漏斗

遵循 [单位经济模型 §2.2](UNIT_ECONOMICS.md)，漏斗中**绝不使用 `累计注册用户` 稀释活跃补贴成本**，全部统计锚定到 `UsageLedger` / `Entitlement` 沙盒事件：

### 2.1 四层核心人群术语
- `registeredUsers`（累计注册用户）：历史创建账号总量。
- `freeMau`（月活免费用户）：当月登录/浏览/上传编辑材料包的免费用户（含零语音消耗）。
- `activeFreeUsers`（月度算力活跃免费用户）：当月真实触发云端 ASR / LLM 彩排的用户（第 10 项补贴分母，基准与付费用户比为 `12 : 1`）。
- `paidUsers`（当月净付费活跃用户）：持有有效 `Event` 或 `Pro` 权益且未全额退款的用户总数。

## 3. 种子期两阶段推进与增长实验计划

对应全团队唯一统一验证节奏：**`第 1 轮 20–30 名真实目标用户 → 第 2 轮扩展至 30–50 人`**（具体门禁细则见 [客户验证方案](CUSTOMER_VALIDATION.md)）：

1. **第 1 轮（`20–30 名` 深度伴跑种子期）**：
   - 不做大水漫灌投流，由团队直连 OPC 创始人（`10–15` 人）与近期有答辩节点的硕博生（`10–15` 人），确保每人跑通至少 `3` 轮完整“编排 -> 彩排 -> 真实上台 -> 复盘”。
   - 验证核心：不靠 `V = H − λI` 单一抽象分说话，重点盯 **误打扰是否破坏临场节奏**、**是否需要更短的 `≤8 字` 词粒度**，以及 **是否愿意在沙盒/模拟付费环节勾选 ¥29 Event 或 ¥59 Pro**。
2. **第 2 轮（`30–50 人` 扩展批验证与 GTM A/B 测试）**：
   - **实验 1（价格弹性）**：对比 `Event ¥19 / ¥29 / ¥39` 在毕业答辩与小型路演中的点击与退单意图差异。
   - **实验 2（声学容错与降级接受度）**：测试当免费 `2×10m` 云端 ASR 用完并提示平滑切换至 `local_sherpa` / `browser_webspeech` 时，用户的流失点是识别精度还是提示不够早。
   - **实验 3（Demo 短片钩子对比）**：对比“防忘词提词”文案 vs “专家突然追问资料外数据时绝不胡说+立即给证据锚点”文案的 `Stage 3 -> Stage 5` 激活率。

## 4. 合规与伦理风控边界（不可逾越的红线）

- **拒绝“隐身作弊”赛道竞争**：如 [竞品与壁垒分析](COMPETITIVE_ANALYSIS.md) 所述，CueX **绝对不做** 屏幕共享隐身伪装、远端面试代答或绕过考试监考的技术能力。所有宣传口径明确指向**公开透明的“演讲与答辩临场提词及防幻觉辅助”**。
- **现场录音与隐私显式告知**：涉及旁听追问转写时，界面保持明确的收音状态指示灯与本地瞬时清理开关，默认只沉淀经过用户自主点击“审批保留”的高频卡点摘要，不默认永久留存原音音频。
- **严谨商业宣传**：在真实商户接口接入与真实订单产生前，任何对外公开材料（BP、官网文案、招募海报）严禁将预期定价或 `Event/Pro` 建模数据写成“已实现流水”或“已跑通付费留存”。
