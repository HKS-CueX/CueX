### 4. 作品介绍 \*
```markdown
【一个被大模型时代忽略的空白】
今天几乎所有大模型都在拼命进化人类的“慢思考”——写万字报告、做深度检索、跑长思维链；前提是你在书桌前，且有人愿意安静等你。
可一旦合上电脑走进真实世界——无论是创业者在游园会与路演现场车轮战答疑、销售顾问面对客户临时砍价与发难，还是深度思考者在求职面试与高压社交中被连环追问——现场往往只给你一秒钟。
卡尼曼在《思考，快与慢》中指出，高压交流时人的注意力带宽极易过载：既容易“当局者迷”，抓不住对方话里的潜台词；又容易在紧张下“嘴跟不上脑子”，明明肚子里有货却调不出底牌。而普通生成式语音 AI 一开口就刷出上百字长段，人在现场根本来不及读，眼神一旦飘向屏幕，交流气场瞬间就断了。

【OPC 的首名全天候 AI 员工：首席临场参谋】
一人公司（OPC）没有公关部、售前团和董秘，主理人每天要在十几种身份间独自切换。CueX 为超级个体打造了一位像“近视眼镜”一样自然融入现场的随身临场参谋（详见附件《AI 员工岗位说明书.pdf》）：

1. 跨场景底牌卡包（无需逐字稿）：无论有稿还是无稿即兴交流，只要把产品手册、报价红线、个人简历或项目背景喂给它，30 秒即可生成对应场次的《场景底牌卡包》，在路演游园会、商务谈判、求职面试之间秒级切换。
2. 看清局势与四级轻引导：严格遵循“无必要不打扰”——顺畅交流时安静隐身（L0）；偏离对方关切给边缘微光轻提醒（L1）；遇到突发追问优先递出 2–6 字关键词点破潜台词、唤醒个人底牌（L2），持续卡壳再展开回应角度支架（L3）；一旦检测到你自己开口接上，未用提示立即自动撤回。
3. 硬核快慢双流架构（上下文给足，省掉 99% 废话生成）：我们没有采用阉割参数的小 LLM，而是把完整底牌放入共享缓存（KV Cache），由 Jev-like 专用快速决策模型并行评估原子问题，每次仅读取 1 个决策 Token 的校准概率（零思维链、不吐废话），配合后台慢思考 Agent 异步备货与输出前复核，兼顾深厚上下文理解与毫秒级响应。
```
