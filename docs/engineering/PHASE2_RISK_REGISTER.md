# CueX Phase 2 Risk Register

> Audit Basis: [PHASE2_AUDIT.md](./PHASE2_AUDIT.md) | Mitigation Tracking: [PHASE2_PLAN.md](./PHASE2_PLAN.md)  
> Rating Scale: **Likelihood** (`High / Medium / Low`) × **Impact** (`Critical / High / Medium / Low`) -> **Severity** (`P0 / P1 / P2 / P3`)

| Risk ID | Risk Description | Audit Ref | Likelihood | Impact | Severity | Concrete Mitigation & Control | Owner |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **`RISK-01`** | **ZIP-Bomb / Inflate Memory Exhaustion via Crafted `.pptx` or `.pdf`**: Unbounded `inflateRawSync` / `inflateSync` in `DocumentExtractor.ts:75-77,314-316` crashes Node gateway under malicious upload. | Q5 | Medium | Critical | **`P0`** | Cap ZIP entries (`<= 512`), enforce `maxOutputLength` per entry & cumulative extracted byte budget, reject excessive compression ratios with `'rejected'` + `VALIDATION_ERROR`, add regression unit tests. | `runtime-server` |
| **`RISK-02`** | **Data Loss on Restart & Unbounded In-Memory `sessions` Map**: Restart drops all reflections/sessions (`GatewayServer.ts:150`); monolithic JSON rewrites risk partial race corruption under concurrent sessions. | Q1 | High | High | **`P0`** | Replace in-memory `sessions` Map and flat JSON stores with WAL-mode `node:sqlite` `StorageRepository` + SQLite transactions and startup schema migrations ([ADR-001](./DECISIONS/ADR-001-modular-monolith-and-sqlite-repository.md)). | `runtime-server` |
| **`RISK-03`** | **Cross-Tenant Data Exposure / Unauthorized Wipe**: Unauthenticated REST & WS endpoints (`GatewayServer.ts:280-420`) allow any reachable client to inspect, patch, or wipe arbitrary `packId`, `sessionId`, or `memoryId`. | Q2 | High | Critical | **`P0`** | Introduce `UserAccount` bearer token authentication (`POST /api/auth/session` + signed session token), enforce `userId` row filtering in `StorageRepository`, keep localhost safety default, return `401`/`403` on mismatches ([ADR-003](./DECISIONS/ADR-003-multi-tenant-auth-and-usage-ledger.md)). | `runtime-server` |
| **`RISK-04`** | **Malformed Input Injection / Burst Abuse**: Direct `JSON.parse(...) as T` without runtime schema verification (`GatewayServer.ts:91,861`) and absent rate limits permit crashes or LLM cost flooding. | Q3 | High | High | **`P1`** | Enforce zero-dependency `validate*` guards from `@cuex/protocol` v2 at every HTTP/WS ingress plus per-user/IP HTTP & WS sliding-window rate limits (`RATE_LIMITED`). | `protocol-architect` + `runtime-server` |
| **`RISK-05`** | **WS Reconnect Replay / Double Metering**: Disconnected WebSocket drops state cleanly or replays unsequenced events; no `idempotencyKey` on `session.start` / `UsageRecord`. | Q4 | Medium | High | **`P1`** | Add `EventEnvelope<TPayload>`, monotonic `serverSeq`, and unique `idempotencyKey` constraints on `UsageRecord` & session actions ([ADR-002](./DECISIONS/ADR-002-event-envelope-and-schema-versioning.md)). | `protocol-architect` + `runtime-server` + `presentation-web` |
| **`RISK-06`** | **Financial Misstatement from `breakevenSessionsPro` & `0.6%` Fee Oversimplification**: Judges or investors mistake session cost headroom for company breakeven, or rely on unverified payment fees/refund exclusions. | Q7 | High | High | **`P1`** | Rename variable everywhere to `maxAffordableSessionsPerProMonth`, add explicit unmodeled `companyBreakeven` disclosure, live-verify WeChat/Alipay fees + refund sensitivity, unify `20–30 -> 30–50` cohort, and gate exports via `verify-metrics-sync.mjs`. | `biz-deliverables` |
| **`RISK-07`** | **Privacy Wipe vs. Statutory Billing & 3rd-Party Cloud Divergence**: Users believe `session.wipe` deletes external cloud LLM/ASR logs or billing audit logs, causing compliance misrepresentation. | Q10 | Medium | High | **`P1`** | Implement `UserDataExportBundle` + `DataDeletionReceipt` explicitly enumerating erased local runtime tables vs preserved `BillingAuditRecord` rows, encrypted backup expiry windows, and 3rd-party API notices (`CONSENT_FLOW.md`). | `auditor-docs` + `runtime-server` |
| **`RISK-08`** | **Legacy Domain Regressions or Dead TTS Reintroduction**: Unused `msedge-tts` / Ming TTS scripts or literal historical domain strings leak back into repo or trigger compliance/competition reviews. | Q8 | Medium | Medium | **`P1`** | Neutralize Phase 1 historical engineering docs cleanly; retire dead TTS code (`ADR-004`); enforce `node scripts/check-legacy-domain.mjs` in `.github/workflows/ci.yml`. | `auditor-docs` + `protocol-architect` + `runtime-server` |
| **`RISK-09`** | **Unscoped Sample ASR Hotwords Corrupt User Vocabularies**: `SAMPLE_ASR_CORRECTIONS` runs globally in `GatewayServer.ts:637,651`, rewriting arbitrary user presentations with CueX pitch jargon. | Q9 | Medium | Medium | **`P2`** | Gate `SAMPLE_ASR_CORRECTIONS` strictly to `pack.isSample === true` or pack-configured domain corrections in Stage B. | `runtime-server` |
| **`RISK-10`** | **Spec-Code-Doc Drift Across Protocol v2 & Stage B Routes**: Documentation (`openapi.yaml`, `asyncapi.yaml`, `README.md`, `PRODUCT_METRICS.md`) diverges from final Stage B routes/events. | Q11 | Medium | Medium | **`P2`** | Stage A drafts specs against `@cuex/protocol` v2 contracts; Stage C runs a mandatory Alignment Gate updating OpenAPI/AsyncAPI/links directly against finalized Stage B `GatewayServer` and `apps/web`. | `auditor-docs` + `qa-verifier` |
| **`RISK-11`** | **Overclaiming Frameworks as Certifications or Offline Eval as Cloud Benchmark**: Readers mistake `OWASP ASVS 5.0.0`, `SLSA 1.2`, `DORA`, or fake-mode eval metrics for audited certifications or real-GPU production telemetry. | Q9, Q11 | Low | High | **`P2`** | Enforce explicit `"engineering alignment reference — NOT third-party certification"` and `[本地离线确定性评测]` vs `[外部硬件未在本 CI 验证]` badges in every doc and deliverable. | `auditor-docs` + `biz-deliverables` |
