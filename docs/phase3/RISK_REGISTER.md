# CueX Phase 3 Risk Register (`Security, Reliability, Honesty & Visual Quality`)

> **Baseline**: Branch `refactor/universal-runtime-presentation` (`7ad6ccb`).  
> **Policy**: Every `Critical`/`High` risk maps to a concrete owner, implementation control, and objective verification test.

| Risk ID | Risk Description & Impact | Severity | Owner | Concrete Mitigation Control | Verification Evidence |
| --- | --- | --- | --- | --- | --- |
| **`P3-RISK-01`** | **Secret / Credential / Personal Path Leakage in Git, Docs, Logs, or Evidence JSON** (`COLAB_ASR_API_KEY`, CPA `apiKey`, SSH private keys, FRP `auth.token`, raw external IPs, `$HOME` literal paths) | **Critical** | All (`@colab-asr`, `@runtime-server`, `@qa-verifier`) | Store runtime tokens, endpoints, and ephemeral TLS cert ONLY in gitignored `.cuex-runtime/.env.phase3.local` and `.cuex-runtime/colab-asr-cert.pem`; enforce `Logger.ts` + `redact()` scrubbing; NEVER embed resolved `$HOME` paths or non-allowlisted public IPs in code/docs/screenshots/board posts. | `node scripts/check-public-data.mjs` (working tree & `--staged`) exits `0` (`0` findings). |
| **`P3-RISK-02`** | **`/v1/responses` Incompatibility & Reasoning Token Starvation on CPA Models** (`system2/config.ts` throws on `openai-responses`; `MAX_OUTPUT_TOKENS = 1024` starves structured JSON when `gemini-4-hydrogen` spends budget on `reasoning_tokens`) | **Critical** | `@runtime-server` | Replace/wrap legacy `$HOME/.prime/agent/models.json` reader in `system2/config.ts` with central `CpaProviderAdapter` supporting BOTH `/v1/responses` and `/v1/chat/completions`, generous output/reasoning token budgets, AbortSignal timeout + circuit breaker, and strict JSON schema validation. | `cpa-llm-report.json` + `@cuex/server` unit & live CPA integration suite. |
| **`P3-RISK-03`** | **Unreported Token Usage Masquerading as `local_rule_zero`** (real CPA HTTP call returns `200` without usage metadata and telemetry records `0` tokens as deterministic free rule) | **High** | `@protocol-architect`, `@runtime-server` | Extend `TelemetryUsageSource` with `'provider_unreported'` (`packages/protocol/src/common.ts`) plus `reasoningTokens` & `correlationId`; propagate explicitly through `SharedCognitiveStateStore` and `StageView` UI badge (`usageSource` never coerced to `local_rule_zero` when `modelCalls > 0`). | Protocol schema tests + `@cuex/server` telemetry tests + UI assertions. |
| **`P3-RISK-04`** | **Silent Fallback Masking Disconnected Colab GPU ASR** (`CUEX_ASR=real` / `colab_gpu` falls back to Web Speech or `TextOnlyAsr` while UI/health continues showing `Colab GPU Active`) | **High** | `@protocol-architect`, `@runtime-server`, `@presentation-web` | Track explicit 7-state `ColabAsrLifecycleState` (`not_configured`..`unavailable`) + `fallbackActive` & `fallbackReason`; push live `asr.status` WS events when port `10086` health drops or mid-stream socket closes; surface honest amber/muted degraded banner in `Navbar` & `StageView`. | Mid-stream WS disconnect & recovery test in `colab-asr-report.json` + Gateway/UI test. |
| **`P3-RISK-05`** | **Unauthenticated or Disk-Retaining ASR Endpoint on Public FRP Port `10086`** (anyone hitting `10086` can transcribe or persist presenter audio chunks on shared Colab disk) | **Critical** | `@colab-asr` | Serve `infra/colab/start_asr.py` strictly over HTTPS + WSS with ephemeral TLS cert (`chmod 600` key on VM), mandatory `Authorization: Bearer <COLAB_ASR_API_KEY>` returning `401` on bad/missing token, frame/body byte limits, and pure in-memory PCM buffering (zero WAV/audio writes to Colab disk). | `colab-asr-report.json` unauthorized `401` rejection test + inspection of `start_asr.py`. |
| **`P3-RISK-06`** | **Orphan Colab Session Mutation or Duplicate VM Spin-Up** (`colab sessions` shows `gpu-g4-s-usw4a1-3rcabnavb0aro` as `[?]`, tempting `colab stop` or second VM allocation) | **High** | `@colab-asr` | Never call `colab stop` on the assigned G4 instance; re-adopt assignment cleanly into `colab-cli` `StateStore` (`name="cuex-asr"`) and verify `colab status -s cuex-asr` + `nvidia-smi` directly. | `colab-asr-report.json` GPU telemetry matching assigned G4 runtime. |
| **`P3-RISK-07`** | **CPA Compiler / Reflection Mutating Locked User Facts or Fabricating Unverified Claims** | **High** | `@runtime-server` | Keep `locked: true` & `verified: true` `Evidence[]` merge/preservation logic deterministic around any CPA LLM extraction/synthesis output; assign `userConfirmed: false` or draft status to new LLM-proposed points unless user locks/confirms; preserve `forbiddenClaims[]` checks & `missingInfoNotice`. | `@cuex/server` compiler & grounding tests (`presentation-doc-compiler.test.ts`, `retrieval-and-providers.test.ts`). |
| **`P3-RISK-08`** | **Synthetic Speech Corpus Misrepresented as Live Room Human Recording** | **Medium** | `@colab-asr`, `@auditor-docs`, `@biz-deliverables` | Explicitly document inside `demo-pack/` manifests, `colab-asr-report.json`, and `REAL_WORLD_VALIDATION_REPORT.md` that the >=12 Mandarin/bilingual WAV files were produced via macOS neural TTS (`Tingting`/`Meijia`) + deterministic acoustic transforms (speed, gain, background noise, pauses/fillers, overlaps), alongside any live mic checks if performed. | Review of `colab-asr-report.json` & `REAL_WORLD_VALIDATION_REPORT.md`. |

| **`P3-RISK-10`** | **Frontend Regression or Viewport Breakage Across Desktop & Mobile Widths (`1440..360`)** (visual regressions, sluggish `> 300ms` transitions during live stage delivery, horizontal overflow on `390/360px`) | **Medium** | `@presentation-web` | Follow all 4 installed frontend skills (`design-taste-frontend`, `frontend-design`, `impeccable` v4.8.0 modes, `emil-design-eng` `< 300ms` custom easing & zero animation on frequent controls); capture & visually inspect AFTER screenshots across all 6 widths (`1440, 1280, 1024, 768, 390, 360`) plus `design-taste-frontend/scripts/inspect.mjs`. | `FRONTEND_AUDIT.md`, `CUEX_DESIGN_BRIEF.md`, AFTER screenshots + E2E zero-overflow assertions. |
