### 4. 作品介绍 \*
```markdown
【一个真实的台上困境】
很多创业者、科研人员和学生在台下想得非常深，可一旦站上路演、毕业答辩或重要汇报的讲台，既要看着评委自然交流，又要应对临场走神与突发追问。
卡尼曼在《思考，快与慢》里揭示了背后的原因：台上流畅表达靠的是“快思考（System 1）”，而一旦遇到突发追问强行启动“慢思考（System 2）”，注意力瞬间不够用，前几秒极易大脑空白。
与此同时，传统滚屏提词器会把眼神锁死在屏幕上，改一句话就错位；普通实时 AI 一秒弹出上百字长答案，台上根本来不及读，越看越乱。

【我们的首名 AI 员工：AI 演讲与答辩临场引导师】
我们认为：AI 回答正确，不等于现场帮得上忙。真正好的临场辅助，不是替你写长稿，而是递给你一个词，点醒你自己。围绕这一理念，CueX 为超级个体（OPC）打造了一位全流程控场数字员工（详见附件《AI 员工岗位说明书.pdf》）：

1. 上台前 · 预编译导播单：提前读懂你的讲稿、PPT 与项目资料，20 秒内整理出一页《演讲导播单》，标好章节时间水位线，并预测评委最可能追问的问题与应对短词；涉及关键数字与承诺均由本人审阅锁定，杜绝台上胡编。
2. 在台上 · 四级渐进轻引导：严格遵守“无必要不打扰”——顺畅脱稿时保持绝对安静（L0）；超时偏题仅给屏幕边缘微光提醒（L1）；忘词或遇到追问优先递出 2–6 字关键词点醒思路（L2），持续卡壳再展开要点短支架（L3）；一旦检测到你自己开口接上，未用提示立即自动撤回。同时提供面向主讲人的极简留白视图（Focus）与面向评委观察的内部决策视图（Underlying）。
3. 下台后 · 证据复盘与重练：按真实时间线定位超时、漏讲与卡壳片段，点击薄弱处即可重练，并迭代下一版导播单。

【从演讲起步，走向每一个快思考现场】
当前我们聚焦打透“演讲与即席答辩”这一高频刚需切口；未来，CueX 的交叉符号 X 将延伸至讲课教学、顾问式销售与求职面试社交，并利用真实场景中“哪一个短词真正点醒了人”的偏好反馈，训练专属于端侧的快思考小模型。
```
