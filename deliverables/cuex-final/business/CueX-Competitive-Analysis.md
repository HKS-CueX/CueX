   - **`[官方事实]` 定价与周期（USD）**：

## 4. 伪护城河否定清单 × 真实工程防线 × 实机全链路锁定

- **我们主动否定的“伪壁垒”**：
  1. 不宣称“让大模型只输出 5 个字”是壁垒（提示词工程极易被复制）；
  2. 不宣称“接入某个云模型或流式 ASR”是壁垒（底层 API 正在商品化降价）；
  3. 不宣称“跨用户共享 KV Cache”是壁垒（真实实现仅为单会话内同前缀缓存节省 `-¥0.020/场`）。
- **CueX 真正可累积的壁垒**：`L0` 静默门控状态机 + 7 类瞬时撤回机制 + `Evidence[]` 白名单强约束 + 基于 `userConfirmed` 的个人记忆飞轮 + `Universal Runtime` 向未来 `Social / Teaching / Sales / Custom` 适配器的代码复用效率。
- **Phase 3 实机延迟与真实消耗已锁定（Cat 3 & Cat 4）**：Google Colab RTX PRO 6000 (`FunAudioLLM/SenseVoiceSmall + fsmn-vad`) 在 14 条可控中文/中英混读测试集（`225.344 s`，`notLiveHumanRoomRecording: true`）上实现 **`52.57 ms`** 平均推理（P95 **`89.59 ms`**，RTF **`0.00327`**，报价数字 `clip_04` **CER `0.0`**，WSS 首包 **`772.1 ms`**）；统一 CPA 网关 **`gemini-4-hydrogen`** 达到 `6/6`（`100%`）S1 状态判断准确率（对比 `gemini-3.5-flash-lite` `4/6`），全链路 `14/14` Section 5.2 场景全过。按实测 `46,357` Token 分布全量从严校准（敏感性 `#12`），单场全变动成本由 Base `¥0.612` 上移至 `¥0.772`，Pro 贡献率仍保持 **`80.2%`**（商业收费仍属假设，离线本地规则底座平均 `0.88 ms` 零 Token）。
