## 二、标准 Osterwalder 九宫格商业模式画布（9 Canonical BMC Blocks）

### 1. 客户细分（Customer Segments） `[商业假设]`
- **P1 首发核心**：OPC 一人公司主理人、种子/天使轮路演创始人、独立商业顾问（高频单兵作战、关键数据零容错）。
- **P2 刚需扩展**：高校硕博研究生（开题、预答辩、毕业答辩及学术 Oral，围绕毕业季与学术截稿呈现强脉冲付费）。
- **P3 长期高留存**：职业讲师、售前解决方案架构师（重复授课与方案宣讲需要沉淀个人白名单与禁忌口径）。
- *范围边界*：`CueX Presentation` 已端到端交付；`Social / Teaching / Sales / Custom` 处于协议注册与路线图阶段 `[Planned]`。

### 2. 价值主张（Value Propositions）
- **品牌承诺**：**在深度思考之外，接住当下**——平时 **`L0` 零字静默**，不制造额外阅读干扰。
- **可控微干预（`L1–L3`）**：仅在遗漏必讲点、卡顿超阈值或遭遇偏航/Q&A 时推送边缘微光（`L1`）、`2–6` 字余光锚点（`L2`）或低频率短纠偏（`L3`）。
- **自动撤回与零幻觉边界**：讲者一旦自行接回或切换章节，卡片自动撤回；问题超出已核准资料范围时诚实提示“缺少证据，不瞎编”。
- **个人记忆主权**：记忆仅记录人类显式勾选批准的习惯与禁区，支持单场或全局一键彻底擦除（`/wipe`）。

### 3. 渠道通路（Channels） `[商业假设]`
- **产品演示自传播**：基于真实对比短片（“聊天式长文 Copilot 现场翻车 vs CueX 偏航瞬时锚点+自动撤回+超纲诚实拒答”）实现自然裂变。
- **精准线下/社群阵地**：怀客松 OPC 社区与创业孵化营（P1 种子直采）、高校硕博论文/答辩社群与毕业季工具包（P2 脉冲转化）。
- **线上官网与体验漏斗**：官网试算与无账号障碍沙盒体验（Web `2 场 × 10m` 免费云端 ASR + 本地降级保底），先复盘再升级付费。

### 4. 客户关系（Customer Relationships）
- **克制且透明的信任伙伴**：通过 `Inspector` 面板完整公开每次决策触发来源、原文依据编号、TTL 倒计时与资源用量，消除黑盒焦虑。
- **非作弊的公开合规姿态**：与专注屏幕隐身作弊的高价面试外挂划清界限，主打“阳光下的专业提词与事实守门员”。
- **人机共治闭环**：上台前必须人工锁定核心数字，上台后随时可点 `Dismiss` 驳回，散场后人工审批记忆写入。

### 5. 收入来源（Revenue Streams） `[商业假设 · 沙盒契约就绪，暂未上线真实商户收单]`
- **`CueX Free (¥0)`**：每月 `2 场 × 10 分钟` 云端流式 ASR + 完整 `Inspector` + 本地/浏览器免费降级通道（承担拉新与口碑，计入 `12:1` 免费补贴成本）。
- **`CueX Event (¥19–39 / 场，锚点 ¥29)`**：`14 天` 有效期，含 `120 分钟` 云端 ASR；Base 净营收 `¥28.42`（扣 `2%` 退款）、变动成本 `¥3.60`、单包直接贡献 `¥24.82`（**直接贡献率 `87.3%`**）。
- **`CueX Pro (¥59 / 月，¥499 / 年)`**：每月含 `240 分钟` 云端 ASR、无限材料包编译与长期审批记忆；Base 月净营收 `¥57.82`、含免费补贴后总变动成本 `¥9.37`、月直接贡献 `¥48.45`（**直接贡献率 `83.8%`**，纯 SaaS 毛利率 **`92.2%`**；单户安全上限 `85 场/月`）。
- **`CueX Team (¥199 / 席位 / 月 [Planned])`**：共享材料白名单与团队口风一致性审计（路线图规划中）。

### 6. 核心资源（Key Resources）
- **Universal Runtime 内核**：与具体显示介质和业务场景解耦的 `InterventionController` 状态机、五重门控仲裁逻辑与 7 类自动撤回引擎。
- **`Presentation` 领域编译器与协议栈**：支持 `.pptx/.pdf/.md/.txt` 抽取并输出带 `verified` / `locked` 标识的 `PresentationContextPack` 与 `@cuex/protocol` 契约体系。
- **用户授权沉淀的私人表达记忆图谱**：经 `userConfirmed === true` 确认的禁用词、高频卡点与 Q&A 防线（与公共模型训练隔离）。

### 7. 关键活动（Key Activities）
- **材料白名单编译与事实锚定**：持续打磨跨格式抽取精度与无依据场景的诚实拒答边界。
- **实时双进程编排与低延迟优化**：协调 System 1 快速检测、System 2 证据检索、单会话同前缀缓存命中与流式 ASR 状态机。
- **配额账本与精细降级运营**：通过 `UsageLedger / Entitlement` 防止超限滥用，确保超出免费云端额度时平滑退回免费本地/浏览器识别通道。

### 8. 关键伙伴（Key Partnerships）
- **实时语音识别生态**：云端商用流式 ASR 供应商（商业基准定价参考 `¥0.80 / 小时`）、阶段验证 GPU ASR 通道（如 Colab RTX PRO 6000 `SenseVoiceSmall`）及开源端侧引擎（`sherpa-onnx`）。
- **推理模型与网关底座**：兼容 OpenAI Responses / Chat Completions 标准的轻/重双模型推理网关，支撑 System 1 与 System 2 分工。
- **合规支付与渠道生态**：微信支付（`0.6%` 标准费率，测试保守情景 `1.0%` 虚拟类目风险）与支付宝（`0.6%` 标准费率，`2026-11-16` 官网核验）；OPC 创业社区与高校学术服务机构。

### 9. 成本结构（Cost Structure） `[云端公开费率 + 模型估算]`
- **十项全可变成本拆解（Base 基准，单场 25 分钟）**：
  - 全可变单场成本 **`¥0.612`** = **云端流式 ASR `¥0.333` (`54.4%`，第一大成本)** + 基础设施/带宽/存储 `¥0.180` (`29.4%`) + 纯 LLM 汇总 **`¥0.098` (`16.0%`)** + 文档解析 `¥0.001`。
  - 其中纯 LLM 包含：System 1 (`¥0.032`) + System 2 (`¥0.068`) + 检索 (`¥0.008`) + 复盘 (`¥0.010`) + **单会话内同前缀缓存节省 (`-¥0.020`)**（严格不宣称跨用户共享 KV Cache）。
- **月度单元负担与保守压力边界**：
  - 计入 `12:1` 免费用户云端补贴（`¥1.257/Pro`）、分渠道支付费与 `2%` 退款损耗后，Base 单 Pro 月度总可变成本 **`¥9.37`**（Conservative 压力情景可承压至直接贡献率 `48.6%` / 29 场上限；Optimistic 达 `94.4%` / 211 场上限）。
- **重要边界披露**：**公司整体固定盈亏平衡点尚未测算**（未计入核心团队研发薪酬、固定服务器底座及市场获客预算）。
